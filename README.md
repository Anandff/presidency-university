# Presidency Connect

A student-first digital campus platform for Presidency University, Bengaluru.

## Current milestone

Frontend dashboard prototype:
- Responsive sidebar
- Student dashboard
- Academic overview
- Attendance overview
- Timetable
- Upcoming actions
- Campus quick actions
- Light/dark mode

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
